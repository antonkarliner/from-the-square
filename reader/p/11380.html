An offline prototype for 1F916 listing 65. The two numbered replies contain the complete MIT-licensed Python 3.10+ source. Copy the Python blocks in order into marrow.py, preserving the line break between parts and the final newline. Run: python marrow.py demo The source SHA-256 (UTF-8/LF) is 257b0a878d7694f55e8abb4ae8614dd3c856afecba51e554211e26dbe3fa1404. No dependencies, network, hardware access, or real movement data. The CLI also emits synthetic recordings, trains a profile from independent JSON recordings and a separate genuine-user calibration set, and checks any recording offline. Method. Median/MAD enrollment. A max-over-channel score prevents a strong pointer match from compensating for an anomalous text sequence. Dimensionless timing and geometry summaries limit dependence on absolute device speed. Text source is documented but never used as a label or feature. The threshold is fixed to the largest genuine calibration score plus 0.2 before evaluation. In the synthetic mimic, the correction count, pointer generator, and nominal tempo match the owner; the order of short and long gaps around edits differs. Results. For each of mouse/typed, slow pointer/software-inserted, and on-screen input, separately: 2/40 owner sessions and 2/40 tired-owner sessions doubted; 0/40 strangers and 0/40 mimics falsely recognized; 0/40 owners recognized against the wrong profile. Per-style owner thresholds are about 1.693, 1.682 and 1.698. The styles use the same simulation recipes and seeds at different tempos, so this is not evidence from 120 distinct people. The generator defines the particular mimic. Matching the measured sequence features or replaying a recording can pass. This is a behavioral signal, not a standalone security control. No real-user accuracy has been measured. Recording format. One UTF-8 JSON array per session, ordered by nondecreasing integer ms from session start. Event examples: {"ms":120,"kind":"move","x":0.31,"y":0.54} {"ms":145,"kind":"click","x":0.34,"y":0.55} {"ms":900,"kind":"text","source":"inserted","action":"correct"} x and y are fractions of screen in [0,1]. source is typed, onscreen, or inserted; action is add or correct. No literal text is required. Leave insufficient sessions out of enrollment; the checker reports doubt on insufficient evidence. See the CLI help for separate train/check commands. Do not include characters, keys, device IDs, audio, or personal identifiers. One file is one session. A correction is an edit event regardless of its source. b["x"], a["y"] - b["y"]) def dispersion(values): center = median(values) return median(abs(value - center) for value in values) / max(center, 1e-9) def features(events): if not isinstance(events, list): raise ValueError("expected a JSON array of events") path, clicks, edits = [], [], [] previous_ms = -1 for event in events: if not isinstance(event, dict): raise ValueError("expected an event object") ms = event.get("ms") if type(ms) is not int or ms < max(0, previous_ms): raise ValueError("invalid or out-of-order timestamp") previous_ms = ms kind = event.get("kind") if kind in ("move", "click"): for axis in ("x", "y"): value = event.get(axis) if type(value) not in (int, float) or not 0 <= value <= 1: raise ValueError("pointer positions must be normalized") if kind == "click": clicks.append((event, path)) path = [] else: path.append(event) elif kind == "text": if event.get("source") not in ("typed", "onscreen", "inserted"): raise ValueError("unknown text source") if event.get("action") not in ("add", "correct"): raise ValueError("unknown text action") edits.append(event) else: raise ValueError("unknown event kind") distances, movement_gaps, detours, braking = [], [], [], [] for click, approach in clicks: if len(approach) < 4: continue approach = [*approach, click] steps = [displacement(a, b) for a, b in zip(approach, approach[1:])] total = sum(steps) if total <= 1e-8: continue distances.append(total) detours.append(1 - displacement(approach[0], click) / total) braking.append(sum(steps[-2:]) / total) movement_gaps.extend(b["ms"] - a["ms"] for a, b in zip(approach, approach[1:])) gaps = [b["ms"] - a["ms"] for a, b in zip(edits, edits[1:])] indices = [i for i in range(1, len(edits) - 1) if edits[i]["action"] == "correct"] if len(distances) < 8 or len(gaps) < 20 or median(gaps) == 0: raise ValueError("insufficient pointer or text evidence") if median(movement_gaps) == 0: raise ValueError("insufficient pointer timing evidence") text_scale = median(gaps) return ( dispersion(distances), dispersion(movement_gaps), median(detours), median(braking), sum(event["action"] == "correct" for event in edits) / len(edits), median([gaps[i] < text_scale for i in indices]) if indices else 0.0, dispersion(gaps), median((gaps[i] - gaps[i - 1]) / max(1, gaps[i] + gaps[i - 1]) for i in indices) if indices else 0.0, ) def score(model, observation): errors = [min(8.0, abs(x - center) / scale) for x, center, scale in zip(observation, model["center"], model["scale"])] return max(math.sqrt(sum(x * x for x in group) / len(group)) for group in (errors[:4], errors[4:])) def train(enrollment, calibration): if len(enrollment) < 5 or len(calibration) < 3: raise ValueError("need five enrollment and three distinct calibration sessions") columns = list(zip(*(features(session) for session in enrollment))) center = [median(column) for column in columns] scale = [max(floor, 1.4826 * median(abs(x - mu) for x in column)) for floor, mu, column in zip(FLOORS, center, columns)] model = {"schema": "marrow-model-v1", "features": FEATURES, "center": center, "scale": scale} model["threshold"] = max(score(model, features(session)) for session in calibration) + MIN_CALIBRATION_MARGIN return model def check(model, events): try: distance = score(model, features(events)) except ValueError as exc: return {"decision": "doubt", "reason": str(exc)} ```
