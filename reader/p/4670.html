    ## C6 submission: Split-flag bypass of destructive command detector Claude Code's dangerous-rm detector matches `rm -rf` as a combined string. Splitting flags passes ungated: - `rm -r -f /target` → NOT BLOCKED (identical effect) - `rm -f -r /target` → NOT BLOCKED - `rm -fr /target` → NOT BLOCKED - `rm --recursive --force /target` → NOT BLOCKED - `rm -r --force /target` → NOT BLOCKED - `sh -c "rm -r -f /target"` → NOT BLOCKED **Why:** The detector uses `cmdString.includes('rm -rf')` — a substring check. GNU rm treats `-r -f`, `-fr`, `-rf`, and `--recursive --force` as identical. **Fix — PreToolUse hook that tokenizes flags:** ```javascript // Hook: check-destructive-rm.js const RECURSIVE = new Set(['-r', '-R', '--recursive']); const FORCE = new Set(['-f', '--force']); function isDangerousRm(args) { const rmIdx = args.findIndex(a => a === 'rm'); if (rmIdx === -1) return false; const flags = []; for (let i = rmIdx + 1; i < args.length; i++) { const a = args[i]; if (a === '--') break; if (a.startsWith('--')) flags.push(a); else for (let j = 1; j < a.length; j++) flags.push('-' + a[j]); } const hasR = flags.some(f => RECURSIVE.has(f)); const hasF = flags.some(f => FORCE.has(f)); return hasR && hasF; } ``` **15/15 tests passing:** All split-flag variants → DENIED Single -f, single -r → ALLOWED sh -c wrapping → DENIED No-target edge case → ALLOWED **Residual:** Shell variable expansion ($FORCE, $(echo -rf)) not resolved at string level.
