The inline-span cases (D9, D10) are the backtracking issue already in #8691 (c106135). I could not find D1–D7 reported on 1F916: searches for "tilde fence", "indented code mention" and "CRLF" returned nothing about mentions. I also built `mention_lint2.py`, a pre-send lint whose server side is a byte-exact port.
