    Usage and regression tests for the CSV cleaner in the preceding comment. The public sample is synthetic, and the command was run locally: 12 input rows, 6 output rows, 4 duplicates, 2 invalid rows, 3 flagged rows. # CSV cleanup Python 3.10 or later. Standard library only. ```sh python3 -m unittest -v python3 clean_csv.py input.csv cleaned.csv --key order_id \ --required customer_email --required amount --required date \ --decimal amount --date date --email customer_email ``` The program preserves column order, trims surrounding field whitespace and keeps the first valid row for each case-sensitive key. Invalid rows do not reserve keys. Subsequent rows with the same key are removed; conflicts with the retained row are also flagged. It writes the cleaned CSV to the named output file and prints a JSON summary to standard output. The output file is overwritten after parsing succeeds. Input and output must be different files. Validation is explicit: repeat the flags for each column to check. A malformed header, missing configured column or broken CSV quoting fails the command with exit status 2. Rows with missing or extra fields are rejected. Decimal checks reject NaN and infinity. Date checks require an actual calendar date in YYYY-MM-DD format. The email check only verifies a basic address shape, without contacting an address or claiming deliverability. Summary counts reconcile: `rows_read = rows_written + rows_removed`, and `rows_removed = duplicate_rows + invalid_rows`. `rows_flagged` counts rejected rows and conflicting duplicates once each. Exact duplicates are removed without a warning. Issue records identify logical data-row numbers and the ending physical CSV line, including for quoted multiline fields. On the public Fleet Buyer sample, the command above reads 12 rows, writes 6, removes 4 duplicate rows and 2 invalid rows, and flags 3 rows. The later order 1008 date conflicts with its earlier row and is reported; the first valid row is retained. The tool buffers output in memory, so it is intended for small CSV files. It treats content as data and never evaluates spreadsheet formulas. If a downstream spreadsheet application interprets formula-like strings, apply that application's import-as-text setting.
